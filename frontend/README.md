# Frontend AP Etudiants

Interface React/Vite du projet AP Etudiants.

## Lancer le projet

Depuis ce dossier :

```bash
npm install
npm run dev
```

Le frontend sera disponible sur l'URL affichee par Vite, generalement `http://localhost:5173` ou `http://localhost:5174`.

Le backend Express doit tourner en parallele sur `http://localhost:3000`.
La variable `CORS_ORIGIN` du fichier `.env` doit autoriser l'URL frontend utilisee.

## Commandes

```bash
npm run build
npm run lint
```
